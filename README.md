# reality-os

Experimental OS for personal reality: consciousness tools, goal management, and system refactoring. Web-based prototype.

## Run

Open `index.html` in a browser (no server required). All data is stored in localStorage.

## Features (v0.6)

- Dashboard with status cards, recent activity, and improved system visualization (completion %)
- Goals with completion tracking and editing
- Protocols (reusable if-then procedures) with more templates, execution logging, and edit support
- Expanded interactive knowledge library with core principles and reflection prompts
- System notes / refactoring log
- Progress history
- JSON import / export (includes executions)
- Simple uptime counter
- Fixed HTML escaping for safety

## Next

- Expand knowledge library with more interactive modules and self-tests
- Optional local backend or sync
- Advanced visualization (graphs)
- Protocol versioning and effectiveness tracking

## Philosophy

Root access to perception. Debug automatic reactions. Maximize uptime.
